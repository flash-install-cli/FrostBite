# Changelog

All notable changes to the Frostbite project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2023-04-30

### Added
- Initial release of Frostbite
- AES-256-GCM encryption for files and directories
- CLI interface with interactive prompts
- Programmatic API for Node.js applications
- Key derivation using PBKDF2
- Support for license keys as additional security
- Ignore patterns with .frostbiteignore
- Key rotation support
- Memory-only decryption for sensitive data
- Runtime API for live project environments
- File watching for automatic encryption/decryption
- Custom file icons for encrypted .fbz files
- Automatic file association during installation
- Comprehensive documentation and examples
- GitHub Pages website with frost effects
